## Basic account commands
Follow on screen instructions.

``` sh
kwk signup
```  
> Note: Usernames will automatically made lowercase.

``` sh
kwk signin
```  

``` sh
kwk signout
```  

### Reset password 

``` sh
kwk reset-password
```

### Change password (after a reset or with existing password)
  
``` sh
kwk change-password
```
